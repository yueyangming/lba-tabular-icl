## Artifact policy

- Released CSVs are frozen records of the main reported analyses.
- New runs must be written under `outputs/`; they should not overwrite `artifacts/`.
- API request logs and model caches are excluded because they are not required to verify the reported aggregate results.
- Timestamps in result rows record the original run and are not expected to match a rerun.
- Hosted-model outputs may drift even with identical prompts and parameters.
